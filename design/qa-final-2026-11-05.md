| # | Bug | Fix | Test |

## Combinations probed (all correct on the merged build; tests added)

`tests/unit/rules/rules_l_batch_combos_test.gd`, `tests/integration/qa/qa_net_evolve_test.gd`:

- **Evolve + Hypnotise (decision).** Hypnotise is a Spell (own turn only) that lasts "until the end of this
  turn", so a borrowed Symbiote is always home before any turn starts. The borrower is therefore never asked;
  the owner is asked at the start of their own turn as usual. A borrowed Spawn whose home zone was filled
  goes to Spent on its return and is not offered. Decision: no special rule is needed; if a future card
  grants longer control, the existing rule (the unit's controller at their turn start is asked) applies.
- **Evolve + Snunday.** The mirror is taken around the evolved base: a Spawn with +6/-4 kept becomes a Larva
  reading 6/0, and under Snunday 0/4.
- **Evolve + Cleanse batch (L20).** The evolved unit keeps its Cleanse, which blocks the whole Paralyse + Burn
  batch of a Frost Wyvern with one stack.
- **Evolve + Loak / Mimic (L11, decision).** Loak copying an evolved Larva shows the Larva art and its kept
  stats. The copy is a snapshot taken On Summon ("become the ATK/DEF/Race of that Unit"), so a Spawn that Loak
  copied and that evolves later leaves Loak's stats and art alone. Evolving a unit drops any copied art it showed.
- **Evolve + Fusion Ceremony (L19).** An evolved material is in Spent, still as its evolved form, before the
  Fusion's On Summon picks targets; it is never offered.
- **Evolve + Debilitate**: already covered (`rules_evolve_test.gd`: a Debilitated Spawn is not offered).
- **Evolve online.** Over real ENet the client gets the prompt with both forms and Evolve / Skip; the host sees
  only "deciding whether to evolve a unit" with no options; the answer travels by index; both seats then see
  the Larva and the public `evolve` event.
- **Evolve in game 2 of a series.** Every game of every soak series started with base cards only (the soak
  checks it at each game start); the series deck lists are never touched.
- **Spectators.** The soak builds a spectator view after every command and checks it never carries a card it
  could not see; the prompt view test covers the spectator's Evolve wait.
- **Bot.** It answered every prompt kind in every soak and arena game (evolve, the Hypnotise zone pick, trap
  windows, material picks): 0 refused commands, 0 stalls.

## Long play

- `tests/perf/qa_soak.gd` (new, headless): full best-of-3 bot-vs-bot series with "spiced" custom decks
  (three Spawns, Hypnotise, two Snundays, Loak, Mimic, Fusion Ceremony, Cleanse/Curse and status cards).
  After every command it checks zone integrity, that ids change only along an Evolve chain, that an Evolve
  prompt only goes to the active player about their own unit, that no seat's or spectator's view carries the
  uid of a card it has never seen, and that every game starts with base forms.
  Run: 40 series, 105 games, 10,843 commands, 88 evolves, 74 Hypnotise steals, 274 Snunday checks,
  1,858 status events: **0 violations, 0 refusals, 0 stalls.**
- `tests/perf/bot_arena.gd` new vs new: 160 games, 0 stalls, 0 refusals; series smoke 12/12 finished.

## Performance

`tests/perf/qa_perf_soak.gd` (new, windowed, 1600x1000): a bot-vs-bot best-of-5 with the spiced decks on
the real GameScreen, a command every 4 frames so the L4 queue builds a backlog; node and orphan counts at
each drained turn start.

- **No leak.** 4 games, 316-400 commands, 33 samples: nodes 597-620 throughout (growth -3 to +10), 0 orphan
  nodes.
- **The authority is cheap:** engine + both views + the screen's render per command p50 4 ms, p95 17.5 ms,
  max 38 ms.
- **Frame time (observation, not fixed):** avg 15 ms (vsync), p95 40 ms, p99 60 ms. The pre-existing probe
  `perf_run.gd` (starter decks) now reads p95 38 ms / p99 49 ms, against p95 12.8 / p99 20.9 ms in October,
  so this is general, not the L batch's combinations. The slow frames are during effects (statuses,
  set pieces), not command handling. For the FX / engine owner: profile the L8 status looks and the
  Forest Ruins table under D3D12 (the 4.6 default on Windows).
